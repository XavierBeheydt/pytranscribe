Un petit script Python, un seul fichier lancé avec uv : il transcrit un enregistrement, repère qui parle, et vous laisse mettre un nom sur chaque voix. Rien ne quitte votre machine.

A small Python script, one file run with uv: it transcribes a recording, finds who speaks when, and lets you put a name on each voice. Nothing leaves your machine.

~/meetings

Ce qu'il faitWhat it does

  • Transcription WhisperX, horodatée au mot près, sur GPU si disponible.
  • Intervenants détectés par pyannote, avec un rapport : temps de parole et première phrase de chacun.
  • Des noms à la place de SPEAKER_00, à la fin de la transcription ou plus tard avec --rename.
  • Tous les formats que lit ffmpeg (m4a, mp3, wav, mp4…), 41 langues, export Markdown ou texte.
  • Transcription with WhisperX, word-level timestamps, on GPU when available.
  • Speakers found by pyannote, with a report: speaking time and first sentence of each.
  • Names instead of SPEAKER_00, right after the transcription or later with --rename.
  • Any format ffmpeg reads (m4a, mp3, wav, mp4…), 41 languages, Markdown or text output.
